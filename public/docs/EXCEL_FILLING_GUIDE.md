# Excel 导入模板填写说明

> 本文档说明如何正确填写碳排放导入模板，以便成功上传到系统。

---

## 快速开始

1. 在系统底部点击「数据管理」按钮，打开上传面板
2. 点击「下载数据模板」获取标准 Excel 模板
3. 用 Excel 或 WPS 打开模板，按本文档规范填入数据
4. 将填好的文件拖拽到上传区域，点击「预览数据」
5. 确认预览数据无误后，点击「确认上传」写入数据库

---

## 通用规则

### 所有 Sheet 通用的固定列

| 列名 | 必填 | 说明 |
|------|------|------|
| 地块名称 | ✅ | 同一地块的 4 行名称必须完全一致 |
| 经度 | ✅ | WGS84 坐标系，范围 [-180, 180] |
| 纬度 | ✅ | WGS84 坐标系，范围 [-90, 90] |
| 年度 | ✅ | 范围 [2000, 2100]，如 `2025` |
| 季度 | ✅ | 只能是 `Q1` / `Q2` / `Q3` / `Q4` |

### 核心规则

1. **同一地块必须填 4 行**（Q1、Q2、Q3、Q4 各一行），缺少任一季度会报错
2. **同地块的固定属性保持一致**：名称、坐标、面积、建筑年代等在 4 行中不能变
3. **枚举值必须使用英文代码**，不能写中文简称，详见下方各类型的枚举对照表
4. **农业区**允许某季度参数为 0（如 Q1 休耕期），其他类型的面积字段不能为 0

## 各 Sheet 填写说明

### 1. 住宅区（Sheet 名：`住宅区`）

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 地块名称 | 文本 | ✅ | |
| 经度 | 数字 | ✅ | |
| 纬度 | 数字 | ✅ | |
| 年度 | 数字 | ✅ | |
| 季度 | 文本 | ✅ | `Q1` / `Q2` / `Q3` / `Q4` |
| 建筑面积(m²) | 数字 | ✅ | 必须大于 0 |
| 建筑年代 | 文本 | ✅ | 见下方枚举表 |
| 常住人口(人) | 整数 | ✅ | 不能为空或负数 |
| 采暖设备类型 | 文本 | ✅ | 见下方枚举表 |

#### 建筑年代枚举值

| 填写值 | 含义 |
|--------|------|
| `before-1980` | 1980 年前 |
| `1980-2000` | 1980 年至 2000 年 |
| `2000-2010` | 2000 年至 2010 年 |
| `after-2010` | 2010 年后 |

#### 采暖设备类型枚举值

| 填写值 | 含义 |
|--------|------|
| `air-pump` | 空调热泵 |
| `gas-boiler` | 燃气壁挂炉 |
| `electric-heater` | 电暖器 |
| `heat-pump` | 空气源热泵 |

#### 填写示例

| 地块名称 | 经度 | 纬度 | 年度 | 季度 | 建筑面积 | 建筑年代 | 常住人口 | 采暖设备 |
|---------|------|------|------|------|----------|----------|----------|----------|
| 示例住宅A | 120.468 | 31.575 | 2025 | Q1 | 120.5 | 2000-2010 | 3 | air-pump |
| 示例住宅A | 120.468 | 31.575 | 2025 | Q2 | 120.5 | 2000-2010 | 3 | air-pump |
| 示例住宅A | 120.468 | 31.575 | 2025 | Q3 | 120.5 | 2000-2010 | 3 | air-pump |
| 示例住宅A | 120.468 | 31.575 | 2025 | Q4 | 120.5 | 2000-2010 | 3 | air-pump |

## 常见错误

| 错误现象 | 原因 |
|---------|------|
| "建筑年代非法值" | 填了中文如"2000-2010年后"，应为 `2000-2010` |
| "采暖设备非法值" | 填了"空调热泵"等中文，应为 `air-pump` |
| "具体子类非法值" | 填了"商场"，应为 `mall` |
| "行业类型非法值" | 填了"精密机械"，应为 `machinery` |
| "学校类型非法值" | 填了"高中"，应为 `high` |
| "水分管理模式非法值" | 填了"间歇灌溉"，应为 `intermittent` |
| "建筑面积必须大于0" | 数值填了 0 或负数 |
| "季度只能是Q1/Q2/Q3/Q4" | 填了"第一季度"或"q1"等，注意大写 Q |
| "年度超出范围" | 填了 1999 或 2101 等 |
| 上传后 500 错误 | Excel 格式损坏、Sheet 名被修改、列头被修改 |

## 完整填写流程

```
1. 下载模板 → GET /monitoring/template/download
2. 用 Excel/WPS 打开，按本文档规范填入数据
3. 上传预览 → POST /monitoring/import（form-data, file=你的文件）
4. 查看返回的 previewPoints 和 errors
5. 如果有错误 → 修改 Excel 后重新上传（重复 3-4）
6. 所有数据无误 → POST /monitoring/import/confirm（body: {"batchId": "..."}）
7. 通过 GET /monitoring/custom-observation-point 验证数据已入库
```
