# AI Agent 使用指南

> 🤖 Carbon AI 智能助手 — 基于 DeepSeek Function Calling + 6 个专业工具

---

## 快速开始

1. 在系统底部点击「AI 助手」按钮，打开对话面板
2. 在输入框中输入你的问题，按 Enter 发送
3. AI 会自动分析意图，调用相应的工具查询数据或执行分析
4. 分析完成后生成 Markdown 格式的回答

---

## 支持的功能

| 功能 | 说明 | 示例提问 |
|------|------|---------|
| **数据分析** | 查询碳排放数据、生成统计图表 | "分析当前季度碳排放数据" |
| **报告生成** | 智能生成多维度碳排放分析报告 | "生成 2025 年碳排放分析报告" |
| **空间分析** | 缓冲区、叠加等 GIS 空间分析 | "无锡学院周围 500 米的碳排放情况" |
| **政策咨询** | 碳达峰碳中和政策解读与合规建议 | "最新的碳达峰政策有哪些要求" |
| **联网搜索** | 实时获取最新的行业资讯和政策动态 | "最新的碳交易市场行情" |
| **Python 计算** | 在沙箱中执行自定义数据计算 | "帮我算一下这组数据的相关性" |

---

## AI 的工作方式

当您提问时，AI 助手按以下流程处理：

```
您的问题
    ↓
① 意图分类 — 判断您想做什么
    ↓
② 选择工具 — 匹配最合适的工具（数据查询 / 联网搜索 / 空间分析 等）
    ↓
③ 执行工具 — 调用后端 API 或 iServer 获取数据
    ↓
④ 生成回答 — LLM 分析结果，用自然语言回复您
    ↓
⑤ 可选渲染 — 空间分析结果自动显示在三维地图上
```

---

## 空间分析示例

AI 助手支持调用 iServer 执行三类空间分析，结果直接在 Cesium 三维地图上渲染：

| 分析类型 | 说明 | 示例 |
|---------|------|------|
| **缓冲区分析** | 在指定位置周围创建缓冲区，统计影响范围内的建筑碳排放 | "分析无锡学院周边 500 米碳排放" |
| **密度分析** | 对排放热点进行密度插值，识别高排放聚集区域 | "显示当前区域的碳排放密度分布" |
| **叠加分析** | 将缓冲区与建筑数据集叠加，筛选出特定范围内的建筑 | "缓冲区内的建筑有哪些超标" |

## 对话管理

- **历史对话**：左侧面板展示所有历史对话记录，点击可继续之前的对话
- **新建对话**：点击「新建对话」按钮开始全新的对话
- **删除对话**：鼠标悬停在历史记录上，点击右侧删除图标
- **停止生成**：AI 正在回答时可点击「停止」按钮中断

---

## 提示建议

- 问题越具体，回答越精准（如"2025 年 Q2 工业区的排放趋势"优于"看看数据"）
- 涉及空间分析时，提供具体地名或坐标
- 生成报告后，自动保存在工作区的「文档」Tab 中
