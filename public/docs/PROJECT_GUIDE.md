# 碳语智图 · 项目使用指南

> **碳语智图** —— 基于 AI Agent 的城市碳排放三维可视分析系统
> SuperMap 杯第二十四届高校 GIS 大赛 · 开发组参赛作品

本文档面向评审与使用者，介绍系统的整体定位、界面结构、四大功能模块以及 AI 助手的用法。

---

## 系统简介

碳语智图是一套面向城市 / 产业园区碳排放管理的三维可视化分析平台。它将 **SuperMap iServer 三维建筑场景**、**PostgreSQL + PostGIS 空间数据库** 与 **DeepSeek 大语言模型（AI Agent）** 深度结合，实现碳排放数据从采集、管理、可视化到智能分析的全流程覆盖。

核心能力一览：

| 能力 | 说明 |
|------|------|
| 三维场景 | Cesium 加载 iServer 三维建筑，支持建筑高亮、相机飞行、点击属性查询 |
| 监测统计 | 按年 / 季度 / 用地类型统计排放总量、占比、强度、同比变化 |
| 空间分析 | 分层设色（Jenks）、极值分析（IQR）、热力图、AI 驱动的缓冲区 / 叠加分析 |
| AI Agent | 自然语言对话，自动编排"查坐标 → 缓冲区 → 三维渲染 → 叠加 → 高亮"全链路 |
| 数据管理 | 标准 Excel 模板导入，预览确认两阶段入库 |

---

## 快速开始

1. **访问系统**：浏览器打开部署地址（本地默认 `http://localhost/twin-carbon/`）。
2. **登录**：使用管理员账号 `admin`，初始密码 `123456`。
3. **首次体验建议**：
   - 先在 **数据总览** 观察整体排放态势；
   - 再切到 **AI 助手**，直接问一句"分析教学楼周围 500 米的碳排放影响"，观看 Agent 全链路演示。

> ⚠️ 演示环境说明：若未连接本地 SuperMap iServer，三维场景显示为天地图底图 + 热力图，完整建筑场景与空间分析需在本地部署 iServer 后体验。

## 数据总览（cloud）

默认进入的界面，用于宏观把握排放态势。

**左面板**
- **各类用地排放强度**：横向条形图，按工业/商业/住宅/教育/农业排序，颜色即该用地类别色。
- **区域显示控制**：色块标签，点击可在地图上显示 / 隐藏对应用地区域。
- **3D 碳排放热力图**：开关 + 参数滑块（拉伸高度、扩散半径、网格密度、透明度、强度幂次），在地图上生成立体热力表面。

**右面板**
- **碳排放概览**：总量、监测建筑数、平均强度、同比变化，附趋势迷你图。
- **各地类占比**：玫瑰饼图，点击扇区可联动下方趋势图聚焦单个用地类型。
- **季度变化趋势**：折线图，支持 1 年 / 3 年 / 5 年尺度切换。

**筛选**：右上角齿轮打开筛选面板，可切换年份（2023–2025）、季度（Q1–Q4 / 全年）、视图模式（标准 / 纯净 / 回溯）。

---

## 达标分析（rotation）

对排放强度做分级与异常检测。

- **左面板 · 分层设色**：基于单位面积排放强度，采用 **Jenks 自然断点** 将各用地内建筑分为 5 级（优秀绿 / 良好黄绿 / 达标黄 / 较差橙 / 超标红），三维场景中对应建筑同步染色。
- **右面板 · 极值分析**：基于 **IQR 四分位距法** 检测异常建筑（区分轻重度高/低四种类型），列出严重异常点位并给出减排建议。

> 选择"全年"季度时，将按年度汇总后再做分级与极值检测。

## AI 助手（heat）

系统最大亮点 —— 通过自然语言驱动数据查询与空间分析，Agent 会展示每一步的工具调用过程。

**推荐体验的问句：**

```
分析教学楼周围 500 米的碳排放影响
对比 2025 年 Q3 和 2024 年 Q3 的碳排放数据，分析变化原因，生成 Word 报告
2025 年工业区的碳排放总量是多少？
```

**你能看到什么：**
- Agent 每调一个工具，右侧出现一张"步骤卡片"（数据查询 / 联网搜索 / 空间分析 / Python 脚本 / 地图渲染等）。
- 空间分析完成后，三维地图自动渲染缓冲区、高亮建筑，并飞行定位。
- 生成的文档可在左侧"工作区 / 文档"页签预览与下载。

**能力一览：** 数据查询、智能分析（Python 沙箱）、空间分析（缓冲区 / 叠加 / 核密度）、三维渲染、报告生成（Word / Markdown）、联网政策检索、文档持久化、链式全链路分析。

## 数据管理（bar）

支持按标准模板批量导入建筑碳排放数据。

1. 在左面板下载 **Excel 导入模板** 及填写指南。
2. 选择 `.xlsx / .xls` 文件，点击"预览数据"。
3. 系统解析五个 Sheet（住宅/商业/工业/农业/教育），校验并计算碳排放，在 **分屏预览** 中展示点位、饼图、趋势与概览。
4. 确认无误后点击"确认上传"，数据 UPSERT 入库，随即可用于三维场景与图表。

---

## 时间回溯

点击底部"回溯"模式，系统按季度（2023Q1–2025Q4）自动回放排放演变：三维热力图、饼图、趋势、强度排名同步刷新，并逐期生成达标与极值分析结论，适合演示数据随时间的变化过程。

## 常见问题

**Q：为什么选择"全年"后三维场景建筑点击不出数据？**
A：该问题已修复。全年模式按年度聚合数据并关联三维建筑 SMID，点击建筑可正常显示全年碳排放。

**Q：三维场景没有建筑，只有底图？**
A：说明当前未连接本地 SuperMap iServer，或 iServer 三维服务未发布。完整建筑场景需本地部署 iServer 并发布三维工作空间（见《部署指南》）。

**Q：天地图偶尔加载缓慢 / 瓦片缺失？**
A：天地图免费密钥有并发限制，系统已对请求限流并自动跳过 429 错误瓦片，稍等即可恢复。

**Q：AI 助手需要外网吗？**
A：需要。Agent 依赖 DeepSeek（对话）与 Tavily（联网搜索），内网或无外网环境无法使用这两项能力。
